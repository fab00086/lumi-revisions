⚙️ Réglages

Choisis « Lumi — voix française » sur iPhone et Android. La première lecture peut prendre quelques secondes.

Teste d’abord le son, puis la voix.

Si Lumi indique que la voix est prête, retouche « Écouter Lumi ». La voix française de Lumi nécessite Internet ; les autres choix utilisent les voix installées sur ton appareil.

📲 Installer Lumi

    Lumi s’ouvre depuis son icône. Une connexion Internet reste nécessaire pour discuter avec l’IA.

    🩺 Diagnostic micro + voix

    Appuie sur le bouton « Lancer le diagnostic » puis accepte la demande de micro si Safari la montre. Le rapport s'affiche en 10 secondes.

    🍎 iPhone / iPad — activer micro et voix
    1. Sur le PC, ouvre Connecter un téléphone et scanne le QR code (adresse HTTPS 🌍 trycloudflare.com). Ouvre ce lien directement dans Safari, en dehors du navigateur de WhatsApp, Facebook ou d'une autre application. Évite l'adresse https://192.168… : son certificat local peut empêcher l'accès au micro.
    2. Appuie sur 🔊 Écouter Lumi dans la conversation, ou Tester la voix dans les réglages. Monte le volume et désactive le mode silencieux (petit interrupteur sur le côté de l'iPhone) : en mode silencieux, la voix de Lumi est coupée.
    3. Appuie sur 🎤 et accepte les demandes d'accès au micro et de reconnaissance vocale. Si tu les as refusées, ouvre les réglages de ce site dans le menu de Safari pour autoriser le microphone.
    4. Vérifie que Siri est activé dans les Réglages de l'iPhone : Safari s'appuie sur ce service pour reconnaître la parole.
    5. Le mode 🎙️ réécoute après les réponses. Si iOS bloque une relance, Lumi arrête le mode et te propose de retoucher 🎤. Si cela continue, recharge dans Safari. Tu peux aussi dicter dans le champ de texte avec le micro du clavier, puis envoyer ta question.

    Le site en ligne utilise déjà HTTPS : aucun certificat ni profil à installer. Si Safari affiche une alerte de sécurité, vérifie l'adresse sans contourner l'alerte.
