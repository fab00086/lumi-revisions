👨‍👩‍👧 Le quotidien

  • Sur le PC : double-clique sur Lancer-Lumi.bat → l'app s'ouvre sur http://localhost:3000.
  • Sur le téléphone (à la maison) : même Wi-Fi que le PC → https://IP-du-PC:3443 (le QR code s'affiche quand on lance le .bat).
  • Partout ailleurs : l'adresse .onrender.com — aucune condition, marche même PC éteint.
  • Installer sur le téléphone : ouvrir l'adresse → bouton Partager (iPhone) ou ⋮ (Android) → « Sur l'écran d'accueil ».

🔐 Changer le code de famille

  1. Render → ton service lumi-revisions.
  2. Menu de gauche → Environment.
  3. Ligne LUMI_ACCESS_CODE → change la valeur → Save Changes.
  4. Render redémarre tout seul (1 min). Le nouveau code est actif — l'ancien ne marche plus (les téléphones redemandent le code une fois).

🆕 Demander une modification de l'app

Les mises à jour se font comme ça : je (Claude) modifie le code → j'envoie sur GitHub → Render redéploie tout seul en 2-3 minutes. Rien à faire de ton côté.

💡 La seule chose manuelle : si je te demande d'ouvrir Render et de cliquer Manual Deploy → Deploy latest commit (onglet Deploys).

✅ Les profils et historiques des enfants sont sur Upstash : ils survivent à chaque mise à jour.

⚠️ Dépannage rapide

🧹 Nettoyage final (quand tout marche en ligne)

  1. Ouvre github.com/settings/tokens
  2. Repère le jeton « Lumi Deploy » → Delete. (On en recréera un nouveau en 30 s la prochaine fois qu'une mise à jour du code est nécessaire.)
  3. Le fichier .env du dossier : ne le partage jamais, il contient ta clé Ollama.
